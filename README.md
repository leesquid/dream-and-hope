# dream-and-hope

꿈과 희망이 가득한 레포 만들기 과제입니다.

![Python](https://img.shields.io/badge/python-3776AB?style=flat&logo=python&logoColor=white)

## gugudan.py
몇 단을 입력하면 해당 단의 구구단을 출력합니다.

```
몇단을 입력할까요? 5
5 단
5 x 1 = 5
...
5 x 9 = 45
```

## turtle_drawing.py
터틀로 그린 무지개 소용돌이입니다.

여섯 가지 색을 번갈아 사용하면서 59도씩 회전하도록 했고, 가운데에는 흰 별을 그렸습니다.

## 실행 방법
```
python gugudan.py
python turtle_drawing.py
```
